# VPS-MONITORING-BOT---INSTALLER

# Installasi
```bash
wget https://raw.githubusercontent.com/winzzy12/VPS-MONITORING-BOT---INSTALLER/main/install_vps_monitoring.sh && chmod +x install_vps_monitoring.sh && ./install_vps_monitoring.sh
```

📁 Installation Directory: 
```bash
cd vps_monitor
```

🚀 To start the bot:
```bash
bash /root/vps_monitor/start.sh
```

⏹️  To stop the bot:
```bash
   bash /root/vps_monitor/stop.sh
```

📊 To check status:
```bash
   bash /root/vps_monitor/status.sh
```

📋 To view logs:
```bash
   bash /root/vps_monitor/logs.sh
```
